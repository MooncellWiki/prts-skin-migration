# 表格定宽迁移（`table-fixed-width`）

2026-10-01 · 机器人账号 BotCathPalug · 规则 `wikibot/rules/skin.py` 的 `TableFixedWidthRule`

## 问题

内容里大量表格写死像素宽度（`{| style="width:800px; display:table"`）。WebKit（iOS 上所有浏览器，
包括 Chrome）的自动表格布局把定长 `width` 当成表格的最小宽度，新皮肤在 <640 时给 `.wikitable` 的
`max-width:100%` 压不住，手机上整页被撑宽、能左右拖。Blink 能压住，所以只有 iOS 上出事。

旧移动站（m.prts.wiki）没出过事，是因为 Minerva 在 <640 时给 `.content table` 写了
`width:100% !important`，把内联宽度整个盖掉了；模板里成片的 `display:table` 则是为了顶掉同一条规则里的
`display:block`。内容本身从来不是响应式的。

## 改法

只改表格开头（wikitext `{|` 行 / HTML `<table>`）里宽于 300px 的定长 `width`，原地替换：

```
width:800px            →  width:min(800px, 100%)
width="800"（属性）     →  去掉属性，style 里加 width:min(800px, 100%)
```

（最早 7 个页面先按「保留旧值、后面追加一条」的写法提交过，随后统一收成上面这一条。
旧值只是给不认 `min()` 的浏览器——2020 年前的 Chrome 79 / Safari 11.1 / Firefox 75 之前——留的回落，
现代浏览器里后一条总会覆盖前一条，去掉它不改变渲染。）

为什么是这个写法而不是 `width:100%; max-width:800px`：要求**现有渲染不变**。

- 桌面：容器不窄于 800px 时 `min(800px, 100%)` 就是 800px，与原来相同；
- Minerva（<640）：`width:100% !important` 把两条声明一起盖掉，与原来相同；
  而 `max-width` 会把本该拉满的窄表封顶，手机端会变；
- 新皮肤 / WebKit：`min()` 不是定长，不触发上面的怪癖，表格不再撑破页面。

### 续：窄屏右侧空框；删掉定宽类（2026-10-03）

**现象**：视口 600–639 时「干员异格任务」外框比内容宽，右侧空出一截框（630 宽下外框 600、表格内容 552）。
不是上面改 `min()` 带出来的，改前（类 `prts-table-600`）一模一样，Minerva 630 宽下同样有（598 / 578）。

**原因**：皮肤在 <640 把正文表格改成 `display:block`：

| 皮肤 | 规则 | 特指度 |
| --- | --- | --- |
| Arknights | `@media (max-width:639px) .mw-parser-output table.wikitable { display:block; max-width:100% }` | (0,2,1) |
| Minerva | `.mw-parser-output table` / `.content table { display:block }`（后者另有 `width:100% !important`） | (0,1,1) |

表格元素变成块，外框按 `width` 拉满；里面的行列落进匿名表格盒，按内容宽度收缩。内容比外框窄就空出一截，内容比外框宽（如 390 宽下）就看不出来。
模板原本写行内 `display:table` 就是为了压过这条规则。2026-06-14 那次「迁移模板表格布局样式」把它挪成 `.prts-table-display { display: table; }`，
特指度 (0,1,0)，两个皮肤里都输，`模板:分支特性信息表格` 从此在窄屏下也空出一大块（630 宽下外框 606、内容 307）。`干员异格任务` 则从来没写过 `display:table`。

**改法**（同一个脚本，`reports/table-width-classes/live-run-2.log`）：

- `MediaWiki:Common.css`（r433585）：`.prts-table-display` 加 `!important`，恢复原来行内写法的效果（皮肤两条都不带 `!important`）；
  同时删掉已经没人用的 `.prts-table-wide-850` / `700` / `600` / `500`（删前补扫用户页 2474 页、模板复扫，都没有引用）；
- `模板:干员异格任务`（r433586）：挂上 `prts-table-display`。随后清了 21 个引用页和 `特勤干员` 的 2 个引用页。

删类和改 `!important` 放在同一次编辑里：CDN 上还留着旧 HTML 的 `分支特性信息表格`（`prts-table-700`，宽 700px），如果只改 `!important`，
它在窄屏下会从块变回表格、按 700px 撑出页面（模拟时 630 宽下整页 712）；类一起删掉后旧副本只是按内容宽度显示。

**验证**：改前在现网 25 页（20 个干员页、两个模板页、`特勤干员` 及其 2 个引用页 电弧 / 机械师）上就地模拟
