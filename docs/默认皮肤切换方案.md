## 1. 现状

### 1.1 MobileFrontend 是怎么挂在 prts 上的

`LocalSettings.php`（打进镜像，三站共用）里 `wfLoadExtension('MobileFrontend')`、`wfLoadSkin('MinervaNeue')`、
`$wgMFMobileHeader = "X-Subdomain"`、`$wgMobileUrlCallback = fn => "m.$domain"`。
真正让某个请求进移动模式的，是 Varnish 在 `m.prts.wiki` 上设的 `X-Subdomain: m`（`$wgMFAutodetectMobileView = false`），
另外两个后门是 `?useformat=mobile` 参数和 `mf_useformat` cookie。

做法：`LocalSettings.php` 里把 MobileFrontend 那段和 `wfLoadSkin('MinervaNeue')` 包进 `if ( $mcMobileFrontend )`
（`$mcMobileFrontend ??= true`，Minerva 留在原来的加载位置，扩展队列顺序不变）。`etc/config.php` 在 `LocalSettings.php`
第 21 行就加载，各站在那里设开关。不设的站点行为与之前逐字节相同。

prts 关掉之后扩展根本不加载，所以：页脚「移动版视图」、`<link rel="alternate">`、`useformat` / `mf_useformat` 后门全都不存在；
Minerva 没装，选了它的用户和 `?useskin=minerva` 由 `Skin::normalizeKey` 回落到默认皮肤。

核对过的两点：

- MobileFrontend 与 MinervaNeue 都**没有注册 ParserOptions**，卸掉不改 parser cache 的键，全站不会重新解析。
- 依赖 MobileFrontend 的只有 MinervaNeue；其它扩展是可选集成（`ExtensionRegistry::isLoaded`）。
- **不能**顺手删 `LocalSettings.php` 的 `$wgDefaultSkin = "vector"`：MW 1.43 的默认值是 `vector-2022`，删了 fgo / mooncell 会变。
  prts 的默认皮肤写在自己的 post-config 里。
