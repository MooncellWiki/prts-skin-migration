## 问题

干员页「获得方式」下的表格在新皮肤的手机上缩成一条窄条，表头「获得方式」「上线时间」一字一行。

表格开头行内写死 `width:40%`。旧移动站（Minerva）在 <640 给 `.content table` 写了 `width:100% !important`，
手机上一直是拉满的（实测 m.prts.wiki 430 宽下 398 / 398）；新皮肤 <640 只给 `.wikitable` 加了
`display:block; overflow-x:auto; max-width:100%`，不改宽度，40% 原样生效（模板行内的 `display:table` 又顶掉了
`display:block`）。

平板 / 横屏手机 / Vector 2022 带侧栏时也不宽：40% 只有 160–300px，表头同样折成两三行。

同类写法全站很少：沙箱库里表格开头宽度 <100% 的只有 3 个模板、44 个条目，40% 这么窄的只有本模板和 3 个条目。
所以只改这一个模板，不动皮肤。

## 改法

宽度从行内挪进 TemplateStyles，表格加 `char-obtain` 类：

```css
.char-obtain { width: 40%; min-width: min(100%, 320px); }
@media (max-width: 639px) { .char-obtain { width: 100%; } }
```

- <640：拉满，与旧移动站、同页其他表格一致；
- 其余宽度：仍是 40%，不到 320px 时保底 320px（表头「获得方式」四个字刚好一行），容器不到 320 就拉满；
- 行内 `display:table` 保留：Minerva 与新皮肤 <640 都给表格 `display:block`，靠它顶掉。
